# versio-imitor-navigator

travelers guide for chasing echoes: a one-page reference for **imitor versio**, the noise engineering twelve-tap stereo delay firmware for the versio platform. every knob by its number on the numbered panel, time, spread, skew and angle drawn out, the lfo, both switches, tap tempo, clock and the holds, the leds, six patches and specs.

source: the noise engineering imitor versio manual.

part of the [versio starsystem](https://mellotom.github.io/versio-navigator/) in the [travelers guide welcome center](https://mellotom.github.io/travelers-guide/).

not affiliated with noise engineering.
